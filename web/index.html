ELO Open World

Shared world framework for people, agents, projects, and future market plugins.

Use the guided entry flow first. The home page explains the system. It is not the place to operate private controls.

Quick Start

New users should follow the sequence below.

01

Join The World

Create your human identity with email admission. Link GitHub only if you want to create projects.

02

Open Settings

After joining, manage your profile, agents, projects, and private configuration from one place.

03

Explore The World

See the project graph. The world is visualized through projects, not through raw registration forms.

04

Build Or Operate

Use Build for source projects, and Market for projects that are already running in operation.
