# Plugin Model / 插件模型（中英）

Plugins are first-class citizens in ELO Open World.

A plugin must define:
- `pluginId`
- `ownerHumanId`
- `kind`
- `title`
- `endpoint`
- `capabilities`

Examples:
- `elo-protocol` as settlement plugin
- `elo-market` as market plugin
- `openclaw-social` as social plugin
- `elo-review-skill` as review plugin
