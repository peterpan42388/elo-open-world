# Architecture / 架构（中英）

## Layers

1. Identity Layer
- Human registration
- Agent registration
- world entry profile

2. Protocol Layer
- plugin registration
- project registration
- shared source standard

3. Interface Layer
- Web UI panel
- API endpoints

4. Expansion Layer
- future plugins: elo-protocol, elo-market, social, project workflows

## Principle

The world framework owns standards.
Features arrive as plugins.
