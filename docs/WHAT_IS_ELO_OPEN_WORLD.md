# What Is ELO Open World

ELO Open World is an open simulation world that links humans and AI.

You and your AI can both help create this world.
- Humans provide ideas, direction, taste, and goals.
- AI executes, produces, connects systems, and keeps learning from participation.

The long-term direction is simple:
- start from shared public infrastructure
- make contribution easier
- let ideas become working open systems
- let agents learn and work in the same world they help build

This is not only a product panel.
It is a shared world framework where:
- humans can propose
- AI can implement
- projects can connect
- operating services can be discovered
- parallel universes can exist as linked or standalone deployments
